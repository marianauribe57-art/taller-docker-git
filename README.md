# Taller Práctico: Docker + Git

Taller de 4 escenarios progresivos con Docker Compose y control de versiones con Git.

**Aprendiz:** Mariana Uribe Muñoz
**Programa:** ADSO - SENA

## Escenarios

| # | Escenario | Stack |
|---|-----------|-------|
| 1 | WordPress + MySQL | WordPress, MySQL/MariaDB, phpMyAdmin |
| 2 | API REST | Node.js, Express, PostgreSQL, pgAdmin |
| 3 | Caché | Flask/FastAPI, Redis, PostgreSQL |
| 4 | CI/CD | GitHub Actions, DockerHub, GHCR |

## Estructura

Cada escenario tiene dos carpetas:

- `ejemplo/` — código guiado de la guía, para estudiar y probar
- `ejercicio/` — desarrollo propio con los requisitos adicionales

## Ramas

| Rama | Propósito |
|------|-----------|
| `main` | Documentación general |
| `escenario-1-wordpress` | Desarrollo del Escenario 1 |
| `escenario-2-api-node` | Desarrollo del Escenario 2 |
| `escenario-3-redis` | Desarrollo del Escenario 3 |
| `escenario-4-cicd` | Desarrollo del Escenario 4 |

## Requisitos

- Docker Desktop
- Git
